# 대림교회 사역 데스크

교역자들이 함께 쓰는 사역 대시보드. 지금은 화면 뼈대 단계로, 모든 내용은 `src/data.js` 의 예시 데이터다.

## 실행

```
npm install
npm run dev      # 개발용으로 띄우기
npm run build    # dist 폴더에 배포용 파일 만들기
```

## 구성

- `src/App.jsx` 화면 (왼쪽 메뉴, 폴더, 내 설교, Todolist, 주간 캘린더, 예배 설교표, 차량 현황)
- `src/data.js` 예시 데이터. Supabase 연결 후 이 파일의 내용이 실제 데이터로 바뀐다
- `src/styles.css` 색과 모양

## 앞으로 붙일 것

로그인(가입 신청과 관리자 승인), Supabase 데이터 연결, 일정 등록, 설교표 수정, 차량 신청(중복 막기), 할 일 추가와 반복, 공지 작성과 단톡방 공유.
