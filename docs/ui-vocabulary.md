# UI 용어 사전 (요약)

출처: 우디디자인랩 'UI 미니 사전' (woodydesignlab.com/ui/dict). 화면 요소를 사용자와 이야기할 때 이 이름으로 부른다.

## 알림과 피드백
토스트(잠깐 뜨고 사라지는 알림) · 스낵바(되돌리기 버튼 달린 하단 알림) · 배너(닫기 전까지 고정 안내) · 모달(답해야 닫히는 확인창) · 바텀시트(아래서 올라오는 옵션 창) · 인라인 오류(입력칸 아래 오류 문구) · 툴팁(ⓘ 눌러 보는 설명) · 코치마크(첫 사용 기능 안내) · 뱃지(숫자 알림 표시)

## 로딩
스피너 · 스켈레톤(회색 박스 자리표시) · 진행 막대 · 원형 진행(목표 달성률) · 단계 표시(2/3) · 버튼 로딩(버튼 안 "저장 중") · 이미지 블러 로딩 · 낙관적 업데이트(서버 응답 전 화면 먼저 반영) · 로딩 바(상단 얇은 막대)

## 입력 폼
텍스트 필드 상태(기본/오류/확인) · 셀렉트(드롭다운) · 세그먼트(붙은 버튼, 예: 월별/주별) · 스위치 · 체크박스 · 라디오 · 슬라이더 · 수량 스테퍼(−/+) · 날짜 선택

## 빈 화면
첫 사용(아직 없어요 + 시작 버튼) · 검색 결과 없음(대안 제시) · 필터 결과 없음(필터 초기화) · 오프라인 · 권한 필요(알림 켜기) · 모두 완료("오늘 할 일을 다 끝냈어요") · 삭제 직후 · 오류 화면(다시 시도) · 잠김(조건 충족 시 열림)

## 제스처
탭 · 길게 누르기(복사/고정/삭제 메뉴) · 스와이프 · 밀어서 삭제 · 드래그(순서 바꾸기 ≡) · 핀치 · 두 번 탭 · 당겨서 새로고침 · 가장자리 스와이프(뒤로)

## 움직임
이즈 인(천천히 출발) · 이즈 아웃(살살 멈춤) · 스프링 · 바운스(완료 강조) · 순차 등장 · 페이드 · 슬라이드(단계 전환) · 확대 전환 · 공유 요소 전환(카드가 상세 화면으로 이어짐)

## 이동 구조
하단 탭바 · 상단 탭 · 드로어(옆에서 나오는 메뉴) · 브레드크럼 · 고정 헤더 · 플로팅 버튼(FAB +) · 페이지네이션 · 무한 스크롤 · 뒤로 가기

## 메뉴 아이콘 별명
햄버거(☰ 전체 메뉴) · 케밥(⋮ 세로 점, 수정/공유/삭제) · 미트볼(⋯ 가로 점) · 와플(격자, 기능 모음) · 벤토(칸 나뉜 격자) · 도너(길이 다른 줄, 필터) · 계단(정렬) · 슬라이더 아이콘(필터 범위)

## AI 화면
생각 중 표시 · 스트리밍 답변 · 추천 질문 칩 · 다시 생성 · 출처 표시 · 답변 피드백 · 고쳐 묻기 · 파일 첨부 · 에이전트 단계

## 다크 패턴 (쓰지 않는다)
숨은 해지 · 미리 체크된 동의 · 가짜 마감 시계 · 죄책감 버튼 · 끼워 팔기 · 가짜 희소성 · 숨은 비용 · 몰래 자동 결제 · 끝없는 권유
